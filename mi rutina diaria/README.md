# Mi Rutina Diaria — Editable

Aplicación Android Java con diseño elegante, pestañas para los siete días y recordatorios.

## Funciones
- Seleccionar lunes a domingo.
- Agregar actividades con nombre, inicio y fin.
- Tocar cualquier tarjeta para editar o eliminar la actividad.
- Activar o desactivar el recordatorio individual (10 minutos antes).
- Guardado local automático, sin internet ni GitHub para cambiar el horario.
- Progreso diario y lista de tareas completadas.
- Los recordatorios se reprograman al guardar cambios.

## Compilar desde GitHub
Sube el contenido de este ZIP a la raíz de un repositorio GitHub (no la carpeta contenedora). En Actions ejecuta `Compilar APK`. Si finaliza correctamente, descarga el artefacto `MiRutinaDiaria-APK`.

Nota: no se ha verificado una compilación Android en este entorno; cualquier error en Actions debe revisarse en el registro de la ejecución.


Ícono personalizado: incorporado en app/src/main/res/mipmap-* y AndroidManifest.xml.
